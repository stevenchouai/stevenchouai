# Steven Chou

**AI builder working on agent systems, personal knowledge infrastructure, and proof-driven engineering.**

I build systems that turn vague AI ambition into inspectable artifacts: source-code research, agent runtime fixes, evaluation harnesses, Obsidian-backed memory, and public proof chains.

## Builder Thesis

Most AI demos stop at the prompt. My work tries to close the loop:

```text
understand agent architecture
→ fix real agent/runtime plumbing
→ evaluate whether agents are worth more autonomy
→ route agents through durable personal knowledge
→ publish the proof chain
```

## How I Build

- **Trace over vibes** — prefer logs, tests, files, commits, reports, and screenshots over claims.
- **Small tools, real loops** — build thin local CLIs and scripts before dashboards.
- **Public proof, not generic portfolio copy** — every project should link repo → artifact → explanation → verification.
- **AI as leverage, not theater** — agents should save judgment and execution time, or they should lose autonomy.
